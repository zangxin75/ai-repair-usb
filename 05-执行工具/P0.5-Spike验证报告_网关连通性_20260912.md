## S3 网关验证 —— ✅ 通过（三项全绿）

| 子项 | 方法 | 结果 |
|------|------|------|
| 五级连通性 | check-network.sh 同款逻辑实测 | 链路✓ 路由✓ DNS✓ 公网✓ 网关端点 POST /v1/messages → 401（可达需鉴权，符合设计判定）✓ |
| 协议+鉴权 | 真实 /v1/messages 中文对话（非流式） | ✅ 正常返回 message 类型，中文回答正确 |
| SSE 流式 | stream:true 中文长输出（数 1-20） | ✅ 收到 45 个 SSE 事件，exit=0，流完整未被网关掐断 |

**结论**：tokeneff.com 网关对 Anthropic API 协议、鉴权、流式输出三项全部兼容，**设计 §2.2.1-C 的网关接入方案成立，P2 可动工**。

**域名等价性实测**：本机配置用 `https://www.tokeneff.com`，方案/脚本写 `https://tokeneff.com`。本次对**非 www 域名补做了带真实鉴权的 POST /v1/messages 测试 → HTTP 200 正常返回**。结论：两个域名的 API 端点完全等价，**脚本与设计文档无需修改，统一保持 `tokeneff.com`**（更短）；`www.tokeneff.com` 登记为等价别名。

**附带发现（重要）**：网关返回体显示上游实际模型为 `glm-5.2`（网关将 claude-haiku 等模型名映射到 GLM 系列）。这意味着：① 模型能力/行为以 GLM 实际表现为准，Live 端 CLAUDE.md 提示词在 P2 真机调试期需按 GLM 实际表现校准；② 选型决策时模型名字段照传 Claude 模型名即可（网关负责映射）。已登记到实施计划开放问题。
