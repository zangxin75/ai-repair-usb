AI 电脑维修 U盘 · 一键制作

插上 U盘，复制一条命令，全自动完成制作。全程中文提示。

⚠️ 制作将清空 U盘全部数据，请先备份！
请使用容量 ≥8GB的 U盘。

第一步：把 U盘 插到这台电脑上

确认 U盘 里没有重要文件（制作过程会清空它）。

第二步：根据你的电脑系统，复制对应命令

🪟 Windows 用户

按 Win + X → 选「终端」或「Windows PowerShell」，粘贴下面的命令后回车：

irm https://tokeneff.com/usb-v1.0.ps1 | iex
不放心？先下载审阅再执行（推荐给维修人员）

irm https://tokeneff.com/usb-v1.0.ps1 -OutFile usb.ps1 下载后用记事本打开审阅， 再运行 powershell -ExecutionPolicy Bypass -File .\usb.ps1。

🐧 Linux 用户

打开终端，粘贴下面的命令后回车：

curl -sL https://tokeneff.com/usb-v1.0.sh | sudo bash

说明：Linux 端脚本不自动下载 Windows 安装镜像；需要的话制作完成后从 微软官网 下载 ISO 拷入 U盘 ISO 目录即可。

🍎 macOS 用户

暂不支持在 macOS 上直接制作。请用 Parallels / UTM 虚拟机安装 Windows 后， 按上方 Windows 方式操作（需在虚拟机设置中把 U盘 直通给 Windows）。

这个命令做了什么？（白话说明，点开查看）
  1. 检查你的电脑权限（Windows 会弹一个蓝色的授权窗口，点「是」即可）。
  2. 从我们的服务器获取最新组件清单。
  3. 找到你插入的 U盘，列出型号和容量让你确认一次——防止选错盘。
  4. 下载维修系统、WinPE、内存检测等组件，并逐个校验文件完整性；Windows 安装镜像则实时从微软官方服务器获取。
  5. 把启动引导层和所有文件写入 U盘。
  6. 最后逐文件复核一遍，全部通过后提示「制作完成，可以拔下使用了」。

整个过程你只需要：复制粘贴命令 + 选择一次 U盘 + 输入一次 YES 确认。

常见问题

Q：弹出一个蓝色窗口问「是否允许此应用更改设备」？

A：这是 Windows 正常的管理员授权提示（UAC）。制作 U盘 必须获得管理员权限，点「是」即可，属预期行为。

Q：杀毒软件或 SmartScreen 弹出提示？

A：脚本需要读写磁盘和联网下载，部分安全软件会提示。本脚本为纯文本、可全文审阅（见上方「先下载审阅再执行」），请确认命令来自本页面后选择「仍要运行/允许」。

Q：制作到一半失败了怎么办？

A：多为网络中断或 U盘 接触不良。重新插拔 U盘 后再次执行命令即可（脚本支持断点续传）。反复失败请换一只 U盘，或记下屏幕上的红色错误提示联系客服。

Q：制作好的 U盘 怎么用？

A：插到需要维修的电脑上 → 开机时反复按启动菜单键（常见 F12 / F9 / Esc，开机画面有提示）→ 选择 U盘 启动 → 自动进入「AI 电脑维修助手」。
