常见问题

U盘插上坏电脑没反应 / 不出现启动菜单？

多为前置 USB 口供电或兼容性问题：换到主板后置 USB 口再开机；台式机优先用机箱背后的接口。仍不行，进 BIOS 确认开启了 USB 启动并关闭 Secure Boot。

AI 服务需要配置 token 吗？要花钱吗？

都不用。制作 U盘 时通过邮箱验证已自动配置，开机即用；附带免费 AI 额度，每周自动刷新。若制作时跳过了邮箱验证，首次开机会有一次输入提示。

办公助手和 Codex 会动我电脑的设置吗？

办公助手全程以普通权限运行，只帮你写文档、算公式、润色邮件，不做任何系统改动（遇到系统问题会引导你切维修模式）。Codex 在你指定的项目目录里干活，重要改动会先征求确认。想删随时整个删掉，不留残余。

做盘时 Codex / Debian 没勾，后来想要了怎么办？

在同一根 U盘上重跑一次制作命令，把想要的项勾上即可补装；已有的 AI 配置和记录不受影响。

U盘丢了怎么办？

登录 tokeneff.com 后在管理页面吊销 Key 即可，他人捡到也无法继续使用。每个 Key 有用量上限，损失有界。

会弄坏我的电脑或数据吗？

维修系统从 U盘独立运行，不依赖坏电脑的硬盘。涉及写入硬盘的操作（重装系统、分区等）AI 都会先列出计划并二次确认。

制作中断网 / 失败了怎么办？

脚本会自动重试；网络恢复后重新执行同一条命令即可，已下载的组件会续用。也可展开「手动下载组件」逐个获取。
