## 项目概述

制作一个支持系统启动的多功能 U 盘：集成 Windows 10/11 安装镜像、Claude Code 及其依赖。U盘启动后自动进入 Claude Code 中文交互界面，服务三类用户：家庭用户（日常维护自救）、上门维修人员（现场诊断维修）、装机人员（新机快速部署）。
