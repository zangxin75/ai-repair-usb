# 重装系统护栏

install-windows.sh 已有盘选择防护与二次确认，本技能补 AI 侧的判断与沟通。

## 前置清单（逐项核对后才调脚本）

1. **数据已保**：问一句「桌面、文档、照片这些要不要保？」
   要保 → 先跑 backup-user-data.sh；用户明确说不要了 → 在确认记录里写明。
   **注意**：目标盘若是 BitLocker 加密且未解锁，普通备份拿不到数据，
   先走 bitlocker-unlock.sh 分支再回来。
2. **盘没选错**：让用户确认电脑型号与目标盘容量，与脚本将清空的盘对上。
   「C 盘」不等于「整块盘」——把「会清空整块盘，D 盘 E 盘所有东西都没了」
   翻译成用户语言讲清楚。
3. **版本确认**：用户知道自己要装哪个版本、原来怎么激活的（数字许可证
   随硬件自动激活，输过密钥的让用户找密钥）。
4. 以上全过 → 调用 `/usr/local/bin/install-windows.sh`，执行其内置二次确认。

## 后置验证（衔接复验技能）

灌装完成后核对：unattend.xml 落位 `\Windows\Panther\`、wimlib 退出码为 0、
分区表状态正常（lsblk 复核分区布局符合预期）。

**管理预期**：向用户交代两段式设计——本步只完成灌装，「重启后由安装环境
完成引导修复与首次配置」，不是「重启就能立刻进桌面」，避免用户重启后
以为又坏了。

## 红线

- 前置清单没走完，不调脚本；用户催也不跳。
- 一切确认完，执行不反复追问——问一遍，确认一次，就动手。
