# 硬盘健康诊断（SMART 解读）

## 入口

优先调 `/usr/local/bin/disk-check.sh`（已封装自检 + 坏道扫描，输出友好）。
需要细看原始属性时：`smartctl -a /dev/sdX`（盘符用 lsblk 确认，别猜）。

## 核心对照表

| 属性 | 判读 |
|------|------|
| `Reallocated_Sector_Ct` > 0 | 已出现重映射扇区，盘在劣化中 |
| `Current_Pending_Sector` > 0 | 有待映射坏块，随时可能扩大 |
| `Power_On_Hours` | 结合用户使用年限判断老化（问一句用了几年） |
| overall 健康但用户报卡顿 | 转向系统/温度/内存排查，不咬死硬盘 |

**SMART 正常但卡顿的排查顺序**：看温度（sensors）→ 看内存。内存检测遵守
CLAUDE.md 约定：不在本系统运行时测（结果不准），引导用户重启时选 MemTest86+。

## 三档结论 + 建议

1. **健康**：无坏块迹象，继续用。卡顿另有原因，转回排查流程。
2. **警告**：少量重映射/待映射 → 直说「这块盘短期内可能恶化，**现在就备份**」，
   现场帮用户跑 backup-user-data.sh。
3. **危险**：大量坏块/待映射持续增长 → 「立即备份 + 换盘，不建议再往这块盘装系统」。

## 关键纪律

给「换盘」结论**之前**，先帮用户把数据备份方案排上（backup-user-data.sh），
再谈换盘型号建议。顺序反了 = 用户先 panic 后抢救，可能直接断电拔盘造成更大损失。

用户提到异响（咔哒/刮擦）时：机械盘物理损伤可能性大，通电越少越好，
转 data-rescue 技能评估是先镜像还是直接送专业机构。
