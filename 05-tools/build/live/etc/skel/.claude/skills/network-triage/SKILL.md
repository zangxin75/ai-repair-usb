# 网络排障（结果翻译 + 兜底）

## 先跑脚本

`/usr/local/bin/check-network.sh` 输出五级结果，本技能把它翻译成人话：

| 级别 | 含义 | 下一步 |
|------|------|--------|
| L1 网卡未识别 | 驱动缺失 | lspci 看网卡型号；firmware-misc-nonfree 已内置，常见无线卡重启即好 |
| L2 拿不到 IP | DHCP/网线问题 | 换网口/重插网线；无线看是否连对热点；路由器重启建议 |
| L3 IP 有但域名解析不了 | DNS 问题 | 换公共 DNS；先 ping 网关确认内网通 |
| L4 出不了内网 | 网关/上游问题 | 建议检查路由器上游；家用环境多为宽带断 |
| L5 网关有响应但 4xx/5xx | AI 服务端问题 | 见下方区分 |

## L5 的关键区分

- **4xx 鉴权类**：服务是通的，只是需要钥匙——按既有约定向用户解释
  「服务正常，token 校验没过」，引导核对 token 配置或重新签发；
- **5xx**：服务端临时故障，建议「等几分钟再试」，不要让用户折腾本地配置。

## 兜底对话

- 脚本判不通、但用户说手机能上同一个网 → 信用户，收脚本原始输出逐级分析，
  不硬套脚本结论。
- 确认离线时主动说明：AI 能力受限，但本地功能不依赖网络——
  硬盘体检、数据备份、密码重置都可以照常做，优先引导用户做这些。
