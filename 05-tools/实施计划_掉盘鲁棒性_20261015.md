### 步骤 4：B 掉盘感知 + nonce 重定位（两侧，方案 §3.2）

| 改动 | 要点 |
|---|---|
| ps1 判定 | robocopy 退出码 ≥8 → `Test-Path "<盘符>:\"`：盘在=拷贝错误重试（本段最多 3 次）；不在=掉盘恢复 |
| 掉盘恢复 | 人话提示 + `Read-Host` 等待回车 → 重枚举可移动盘 → 读根 `.ai-repair-maker-session` nonce 与本机 `cache\session-nonce` 比对 → 匹配更新**脚本级 `$root`**（sh `$MNT`）后续传引用 → 重调拷贝（文件级幂等）。nonce 不匹配=提示插错盘继续等；标记文件损坏→卷标匹配+用户确认兜底 |
| nonce 写入时机 | **Ventoy 段完成、数据分区盘符确定之后**（全新 /I 会清盘，勿早写）；sh 同构 |
| 三振 | 同一组件失败**累计** ≥3 次 → Die，文案含「下载缓存保留在本机，换盘重跑无需重新下载」。**三振/降级分类表（定死语义，不得自行解读）**：①盘不在/mountpoint 失败 → 走恢复路径 + 计 1 振；②盘在且拷贝重试 3 次仍败 → 计满 3 振 Die；③**非 I/O 类确定性错误（如暂存入口缺失、sha 校验不过）→ 不计振，保留原 installed=false 降级**（ps1:1010-1013/1026-1029/1041-1044 的「逐项可失败降级」特性不变）。smoke 补语义锚：降级分支仍含 `Write-Warn` + `installedFinal = $false` 字样 |
| sh 判定 | rsync/`copy_progress`（pv/dd，sh:541-550，非裸 cp）退出码非 0 → **`mountpoint -q "$MNT"`**（NOT `[ -d "$MNT" ]`——MNT 是 WORKDIR 下挂载点目录，掉盘后空目录仍在，`[ -d ]` 恒真、永远进不了恢复分支，sh:535）。恢复路径需：`umount "$MNT" || umount -l "$MNT"`（lazy 兜底，防 EBUSY/挂起）→ 等新 `/dev/sdXN` → **nonce 重定位**：每个候选分区临时挂到 `$WORKDIR/probe` → 读 nonce → 匹配者挂到同一 `$MNT` 路径、其余立即 umount（`$MNT` 路径不变则后续代码零改动）。sh 目标平台=Linux（头部自认 + 已硬依赖 lsblk sh:70），`mountpoint` 随 util-linux 必在，macOS 不在支持范围 |
| **旧断盘哨兵改造** | ps1:1047-1051 现逻辑 `config 目录不存在 → 文案「已写入的部分无需保留，建议换盘重做」+ exit 1`，与本轮「已拷贝不重拷、缓存保留」承诺正面矛盾且绕过恢复路径。改为：走掉盘恢复路径；若保留快退则文案改「重新插好U盘后重新运行制作器，已下载内容无需重新下载」。sh 侧同构哨兵同步检查 |
