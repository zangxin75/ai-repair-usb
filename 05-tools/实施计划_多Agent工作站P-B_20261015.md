打包方法（`buildhost:~/ai-repair/pb-prepack/pack.sh`，可重跑）：
- `npm i --prefix <dir> --omit=dev --os=win32 --cpu=x64 --ignore-scripts <pkg>@<ver>` → win32 原生二进制树（koffi/node-pty/esbuild/clipboard 的 win32-x64 变体都在，linux 变体排除）
- `tar czf --dereference` 烤平 `.bin` 符号链接（exFAT 兼容，设计 R1 规避）

排雷：
1. **平台二进制**：默认 npm install 在 Linux 上只装 linux 变体（pi 树曾混入 clipboard-linux-x64-gnu）——必须 `--os=win32 --cpu=x64` 强制。
2. **openclaw preinstall 版本闸**：要求 Node ≥24.16；绕过用 `--ignore-scripts`（预编译二进制包无需 install 脚本）。**连带约束：便携 Node 必须发 v24 LTS**（首版误打 v22.14.0 已作废重打 v24.22.0）。
3. dist/ 目录 root 属主，拷贝产物需 sudo。
4. OpenClaw 入口实测是包根 `openclaw.mjs`（设计文档的 dist/cli.js 是占位名）；Pi 入口 `@mariozechner/pi-coding-agent/dist/cli.js`（bin=pi）。

## 3. 契约要点（改前必读）

- **agents.json 新语义**：`openclaw`/`pi` 条目仅在发布清单提供该组件时写入（`userDeclined`=制作时未勾；`node` 条目同规则）；启动器「无记录→隐藏」兼容存量盘。
- **入口路径**（启动器与制作器双方硬编码，改包必须同步）：`bin\node\node.exe`；`bin\openclaw\node_modules\openclaw\openclaw.mjs`；`bin\pi\node_modules\@mariozechner\pi-coding-agent\dist\cli.js`。
- **不经 npm run**（exFAT 无 .bin 符号链接），全部 node 直启。
- **版本耦合**：openclaw 预装包要求 Node ≥24.16 —— manifest 里 node 组件不得回退 v22。
- Pi 包名是 `@mariozechner/pi-coding-agent`（设计文 §3.5 写的 `@mariozechner/pi` 是旧称）。
